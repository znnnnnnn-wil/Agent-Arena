# Quaternius 3D assets

The files in this directory are selected and web-optimized derivatives of
Quaternius asset packs. The models, textures, rigs, and animations remain
available under the CC0 1.0 Universal public-domain dedication.

## Universal Base Characters

- Source: https://quaternius.com/packs/universalbasecharacters.html
- Distribution: `Universal Base Characters[Standard].zip`
- SHA-256 of downloaded archive:
  `FDBF1804C90DFC1EA03E992BFF7DA2DFD1A79318E13270A660180F9308455F40`
- Included here: male and female Superhero glTF characters and resized textures.
- Local license: `universal-base/LICENSE.txt`

## Sci-Fi Essentials Kit

## Universal Animation Library 2

- Source: https://quaternius.com/packs/universalanimationlibrary2.html
- Distribution: `Universal Animation Library 2[Standard].zip`
- SHA-256 of downloaded archive:
  `4008EA208A604773A2B2177D965F0F5D3195498B5BF838C3F5785D68E95F2A68`
- Included here: compact JSON exports of ten idle, locomotion, interaction,
  combat, reaction, and confirmation clips used by live game events.
- Local license: `animations/LICENSE.txt`

Texture resizing and animation JSON extraction were performed only to reduce
browser download and memory costs. No additional usage restrictions are added.
