# 大逃杀规则完善与验收记录

日期：2026-10-01。

本次针对规则漏洞、AI 特殊行为偏少和结算一致性进行了代码修复。历史研究报告对应较早版本，不能直接作为本次改动前的行为基线。

## 已完成的修复

| 问题 | 修复方式 |
| --- | --- |
| 最后一位玩家的社会行动、奖励和履约尚未完成就结算轮次或赢家 | AI 回合按战术、记忆与关系、通信、社会行动、隐藏目标、轮末环境、到期处理、终局依次执行；结束事件保持最后 |
| 模型失败或限流后只做普通战术，缺少社会行为 | 本地回退增加履约、联盟、交易、信息购买、目标贡献与传闻选择，以及相应通信 |
| 社会候选被靠前类别占满 | 为不同类别分配名额，轮换交互对象，保留无社会行动选项与批量目标贡献 |
| 战术和社会行动互相冲突 | 提供可配对战术 ID；检查移动后的区域、代谢与战术消耗后的资源；执行时再次校验实际状态 |
| 已执行部分动作后发生异常，再执行回退导致重复扣费 | 模型调用与动作执行分离，执行异常不再触发第二次战术动作 |
| 空投反复占领可以重置争夺 | 已有占领者时禁止重复占领；离开、倒地或隐藏中断占领；本地策略会守住自己的占领 |
| 少量护甲奖励反而降低原有高护甲 | 护甲增益统一保证不会降低当前护甲 |
| 情报可重复出售，或传闻被记为确定事实 | 阻止重复待处理销售与已知情报购买；交易完成事实和传闻内容分别记录，传闻保留原可信度 |
| 履约资源预算与交易候选受到错误限制 | 食水考虑代谢，医疗包与弹药不额外扣食水式储备；已有承诺仍可提出交易 |
| 本地策略缺少救援、守空投、目标移动与终局竞争 | 增加相应情境选择、多跳撤离危险区，以及晚期竞争时的背叛策略 |
| 事件轮次与社会动作失败难以排查 | 动作事件记录实际轮次；失败社会行动提供内部原因及公开通用提示，界面支持展示 |

## 验证结果

- 全量 Maven 测试：317 项，失败 0，错误 0，跳过 0。
- 新增规则回归测试：14 项，覆盖终局奖励、截止轮履约、动作不重放、候选兼容、空投、护甲、情报、撤离、联盟及模型失败回退等。
- 新增本地策略整局测试：30 局，种子 910000–910029；轮换使用 6、8、10 名玩家，停止轮次为 20，初始食水为 5；共 2935 次决策。
- 30 局全部正常结束，每次决策后检查状态不变量，未出现不变量异常。
- 前端脚本通过 `node --check`，本次代码改动通过差异空白检查。

## 结果边界

本次整局验证使用生产 AI 回合入口及本地启发式策略，没有调用真实付费模型。统计证明修复后的本地路径能够执行多种社会行为并完成整局，不能直接推断真实模型的特殊行为频率或整体胜率变化。

救援和情报交易成功仍然较少，依赖倒地、位置、买家已知信息等场景条件。后续真实模型验收应分别记录候选是否出现、模型是否选择、配对是否有效、执行是否成功和收益，而非只统计最终事件数量。本次没有强制每局出现某种行为，也没有据此宣称全部数值平衡问题已经解决。

## 主要代码入口

- `BattleAiGameRunner`：回合执行顺序、模型失败回退及事件轮次。
- `BattleRoyaleGameEngine`：轮末与终局结算、空投占领。
- `BattleSocialDecisionCandidateGenerator`、`BattleSocialCandidateCompatibility`：社会候选覆盖与组合预算。
- `BattleHeuristicCandidateSelector`、`BattleHeuristicSocialCandidateSelector`：本地战术与社会策略。
- `BattleInformationTradeSystem`：情报交易去重与记忆可信度。
- `BattleRuleImprovementsTest`、`BattleLocalGameSmokeTest`：规则回归与整局验证。
